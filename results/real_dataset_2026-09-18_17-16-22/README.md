# Real-world evaluation dataset (2026-09-18T17:38:13)

Назначение: независимый ручной evaluation set для объективной оценки качества ASR (T-one).

- НЕ используется для fine-tuning T-one.
- НЕ является источником hotwords: hotwords строятся только из streets.txt.
- Используется только для сравнения декодеров/моделей на одних и тех же WAV + reference;
  WAV и reference остаются неизменными между экспериментами.

Источник улиц: /Users/dimgalin/MyProjectsVSCode/t-one-train/streets.txt (sha256 6981fcad241d…), улиц: 109.
Порядок и написание — ровно как в streets.txt; слова «улица»/«переулок» не добавляются.

Варианты записей:
- FULL — дословная строка из streets.txt; ничего не добавляется и не склоняется.
- SHORT — короткий вариант, который пользователь вводит сам перед записью
  (например «Хисматуллина»); ENTER или «-» — пропустить запись.
- NATURAL — реальная фраза, которую пользователь вводит сам перед записью
  (например «До Абзелиловской»); ENTER или «-» — пропустить запись.
SHORT/NATURAL не генерируются программой: ни сокращений, ни склонений названий.
reference всегда соответствует реально произнесённой фразе;
пропущенные записи сохраняются со status="skipped".

Аудио: mono, 8000 Hz, PCM16 WAV; запись на native sample rate микрофона,
перед сохранением resample в 8 kHz; без шумов, кодеков и усиления.
Запись ручная: ENTER старт/стоп, без VAD.
